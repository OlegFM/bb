# Windows test-exclusion audit

Source inspection on 2026-09-16 at Phase 4 base `fafaf454a`.
This is a classification of coverage, not a claim that the listed suites passed
at the Phase 5 head. New installer tests run only where PowerShell is available.

Search included `skipIf`, inverse `runIf`, and aliases assigning `describe.skip`
or `it.skip` from process.platform, across apps, packages and plugins. Generic
optional-corpus, missing-build-output and missing-npm/Git skips also need their
prerequisites present in CI; they are not Windows support exceptions.

Update on 2026-09-23: the workspace suite passed 179 tests with 7 platform
exclusions; after the final failure-cleanup-only test correction, the entire
fetch file passed again (6 passed, 1 POSIX exclusion). See the precise run
boundaries in [local hardening evidence](05-local-hardening.md).

The five substantive Windows exclusion gaps identified by this inventory are
closed locally by Tasks B and D, including the additional false npm prerequisite
gap discovered during hardening. Task E's final full server run passed 2505
tests with 24 skips: 22 POSIX shell cases, one POSIX 0600 case with a native ACL
counterpart, and one optional-corpus pagination case. Two optional-corpus files
were skipped; empty data-driven rows add no enumerated test cases.
This does not establish that every repository test passes: other non-gating
packages, external CI and manual acceptance retain their separate gates.
Do not mark native Windows supported from this
inventory alone.
